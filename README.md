# 🔥 Featured Project

## 🧠 DevLens — AI Code & Documentation Assistant

**DevLens** is a RAG-powered AI developer tool that helps developers understand, explore, and interact with their codebases using natural language.

### ✨ What it does

- 📁 Upload source code, documentation, files, and project folders
- 🔎 Process and retrieve relevant project context
- 🧠 Use Retrieval-Augmented Generation to answer questions
- 💬 Interact with uploaded projects through conversational AI
- 📚 Understand unfamiliar codebases faster
- 🤖 Integrate LLM capabilities into a practical developer workflow

### 🛠️ Tech Stack

**React · Node.js · Express.js · PostgreSQL · Qdrant · RAG · Embeddings · Gemini · Docker**
