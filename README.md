# 🔥 Featured Project

## 🧠 DevLens — RAG-Powered AI Code & Documentation Assistant

**DevLens** is an AI developer tool that answers questions from uploaded code and technical documents using Retrieval-Augmented Generation (RAG).

### ✨ What it does

- 📁 Upload source code, documentation, files and project folders
- ✂️ Process documents and split them into text chunks
- 🔎 Retrieve the most relevant context with Qdrant vector search
- 🧠 Generate answers with Gemini AI, grounded in the uploaded project
- 💬 Conversations, project and document management, and user authentication

### 🛠️ Tech Stack

**React · Node.js · Express.js · PostgreSQL · Qdrant · RAG · Gemini AI · Docker**

🌐 **Live Demo:** https://rag-dev-lens.vercel.app/
📂 **Repository:** https://github.com/PraveenNagaraj77/RAG-DevLens
